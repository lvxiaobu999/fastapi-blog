# 博客知识助手实施清单

本文是未来编码时的执行清单，不表示当前项目已经具备这些 AI 能力。实现时仍需逐条阅读相关 Router、Schema、Service、Model、Migration 和测试，并遵守仓库数据库安全约定。

## Phase 0：定义基线

- 收集 30 至 50 个真实问题，标注期望文章、答案要点、允许无答案与否。
- 记录当前文章数量、语言、平均正文 token、更新频率和权限规则。
- 明确 SLO、单请求预算、隐私保留期和支持/不支持的问题范围。
- 用现有关键词搜索跑一遍基线，保留 Recall@k 和失败案例。

## Phase 1：准确的文章搜索助手

- 新增 AI 请求/响应 Schema，限制问题长度并禁止额外字段。
- 新增 AI Router；复用认证、请求 ID、限流和异常处理。
- 新增 Orchestrator Service；不要把模型逻辑塞进 Router。
- 复用或扩展文章搜索 Service，只返回已发布且用户有权访问的文章。
- 接入模型的结构化输出与超时；引用从查询结果组装，不能由模型自由生成。
- 支持模型故障时降级为普通搜索结果。
- 测试成功、空结果、422、401（如要求登录）、限流、超时和伪造标题。

## Phase 2：RAG 索引

建议新增的逻辑边界，而非强制文件名：

```text
app/schemas/ai.py          AI 请求、回答、引用和反馈契约
app/routers/api_ai.py      HTTP/SSE、认证、状态码和错误转换
app/services/ai/           编排、Prompt、模型客户端、检索与引用
app/models/                会话、消息、文档块（确需持久化时）
tests/ai/                  检索、生成、工具、安全和 API 测试
```

- 为 chunk、Embedding 模型、维度、内容哈希、文章版本和元数据设计 schema。
- 新建 Alembic Migration，并人工检查 upgrade/downgrade；不修改旧迁移。
- 实现 Markdown 解析与按章节切块，保留来源位置。
- 实现发布/更新/下架的增量索引和失败重试。
- 实现全文 + 向量混合检索、元数据过滤和可选 rerank。
- 引用精确到文章与章节/片段，验证引用确实支撑答案。

## Phase 3：会话和流式体验

- 使用 SSE 实现 token/事件流；事件至少区分 metadata、delta、citation、done、error。
- 客户端支持取消、重试、断线提示、引用跳转和禁止重复提交。
- PostgreSQL 保存会话及消息；按需要在 Redis 缓存活跃会话。
- 实现最近窗口 + 摘要，并显式计算 token budget。
- 提供会话删除和数据保留策略；默认不做隐式长期画像。

## Phase 4：工具与 Agent

- 先实现只读 `search_posts`、`get_post`，再考虑写工具。
- 工具参数使用 Pydantic 二次校验，执行层使用当前用户权限。
- 收藏等写操作需要确认、幂等键和审计；发布/删除默认不开放给 Agent。
- Agent 设置最大步骤、总超时、费用上限和重复调用检测。
- 固定流程写成代码工作流；只有动态路径才交给模型选择。

## Phase 5：评测、可观测与发布

- 单元测试使用 fake model，集成测试使用隔离数据库和可控响应。
- 固定数据集分别评测 retrieval、generation、tool use 和安全。
- 对 Prompt Injection、跨用户/草稿泄露、超长输入和循环工具调用做红队测试。
- Trace 记录 Prompt/模型版本、文档 ID、工具事件、token、费用和延迟，但不记录敏感正文与密钥。
- 使用功能开关和小流量灰度；准备模型不可用、向量索引不可用和超预算时的降级。

## 建议的 API 边界

```text
POST   /api/ai/conversations                 创建会话
GET    /api/ai/conversations                 当前用户会话列表
DELETE /api/ai/conversations/{id}            删除会话
POST   /api/ai/conversations/{id}/messages   提问；SSE 返回运行事件
POST   /api/ai/messages/{id}/feedback        点赞/踩与原因
```

若 MVP 只做单轮问答，可以先使用 `POST /api/ai/chat`，不要提前建立全部复杂资源。

## Definition of Done

- API 契约、权限、事务和错误状态清晰。
- 答案基于当前可访问文章，引用真实，无证据不编造。
- 评测集结果达到预设阈值，关键失败案例已回归。
- 超时、重试、取消、限流、降级和预算均有边界。
- 日志与 Trace 可定位问题且不泄露敏感数据。
- 数据库迁移、索引更新、删除传播和回滚方案已验证。
- `docs/开发流程.md` 记录实际新增文件、请求链、数据库影响和验证命令。
