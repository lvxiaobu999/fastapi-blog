# AI 应用开发必读文档与学习资源

本文件是资料库，不是需要从上到下学完的课程表。实际顺序以 [04-学习路线与实战面试标准.md](04-学习路线与实战面试标准.md) 为准：路线走到哪个阶段，只打开该阶段明确指定的资源。资源会更新，优先读官方文档的当前版本，再用课程建立直觉。

## 1. 必读官方文档

### 模型与 Agent API

- OpenAI Platform Docs：Responses API、Structured Outputs、Function Calling、Embeddings、Streaming、Evals、Safety、Prompt Caching 和 Agents SDK。入口：<https://platform.openai.com/docs>
- Anthropic Docs：Prompt Engineering、Tool Use、Context Windows 和安全实践。入口：<https://docs.anthropic.com/>
- Google Gemini API Docs：模型、结构化输出、Function Calling 和多模态。入口：<https://ai.google.dev/gemini-api/docs>

先选一个供应商完整做通，再横向比较。具体模型名、价格和限制变化很快，以官方页面为准。

### RAG 与数据

- PostgreSQL Full Text Search：<https://www.postgresql.org/docs/current/textsearch.html>
- pgvector：索引类型、距离函数和过滤：<https://github.com/pgvector/pgvector>
- Hugging Face Course：Tokenizer、Transformer、Embedding 和模型生态：<https://huggingface.co/learn>
- Pinecone Learning Center：向量检索和 RAG 概念文章，即使不用 Pinecone 也有参考价值：<https://www.pinecone.io/learn/>

### Agent、协议与框架

- Model Context Protocol 文档：理解 host/client/server、tools/resources/prompts 与安全边界：<https://modelcontextprotocol.io/docs>
- LangGraph 文档：学习持久化状态、节点/边、checkpoint 和 Human-in-the-loop：<https://langchain-ai.github.io/langgraph/>
- LlamaIndex 文档：重点阅读数据摄取、索引、检索和评测：<https://docs.llamaindex.ai/>
- Microsoft AutoGen 文档：用于理解多 Agent 模式，但不要把它作为入门第一站：<https://microsoft.github.io/autogen/>

框架 API 更新快。学习时必须能脱离框架解释模型调用、消息、工具、状态和检索的底层数据流。

### 安全、评测与可观测性

- OWASP Top 10 for LLM Applications：<https://genai.owasp.org/llm-top-10/>
- NIST AI Risk Management Framework：<https://www.nist.gov/itl/ai-risk-management-framework>
- OpenTelemetry 文档：<https://opentelemetry.io/docs/>
- Ragas：RAG 评测方法与实现：<https://docs.ragas.io/>
- promptfoo：Prompt、模型和红队回归测试：<https://www.promptfoo.dev/docs/>

## 2. 高质量课程与视频

- DeepLearning.AI Short Courses：`ChatGPT Prompt Engineering for Developers`、`Building Systems with the ChatGPT API`、`Building and Evaluating Advanced RAG Applications`、`AI Agentic Design Patterns with AutoGen`。适合快速建立工程直觉：<https://www.deeplearning.ai/short-courses/>
- Full Stack Deep Learning：LLM Bootcamp / Generative AI 课程，覆盖产品、数据、部署和评测：<https://fullstackdeeplearning.com/>
- Hugging Face Agents Course：从工具到 Agent 的实践课程：<https://huggingface.co/learn/agents-course/>
- Andrej Karpathy 的 `Intro to Large Language Models` 和 `Let's build GPT`：前者建立全局认识，后者理解底层原理。YouTube 搜索作者和准确标题，以作者官方频道版本为准。
- Stanford CS336 / CS224N 公开课：想深入模型训练和 NLP 原理时再学；应用开发初期不必先啃完。

中文视频可以作为辅助，但要检查发布时间、源代码和官方 API 是否已经变化。一个实用筛选标准是：教程是否包含失败处理、评测、安全和成本；如果只有“几十行代码实现 Agent”，不应作为主要学习材料。

## 3. 值得持续阅读的文章/作者

- Lilian Weng：Prompt、Agent、幻觉等综述，信息密度高：<https://lilianweng.github.io/>
- Chip Huyen：AI Engineering、LLM 应用评测和生产系统文章：<https://huyenchip.com/blog/>
- Eugene Yan：推荐、搜索和 LLM 系统的工程文章：<https://eugeneyan.com/>
- Simon Willison：LLM 工具、Prompt Injection 和实际开发观察：<https://simonwillison.net/>
- Anthropic `Building effective agents`：区分 workflow 与 agent，适合建立正确架构判断；在 Anthropic Research/Engineering 官方站内检索标题。

## 4. 传统工程文档不能跳过

- FastAPI、Pydantic v2、SQLAlchemy asyncio、PostgreSQL 和 Redis 官方文档。
- Docker、Kubernetes 基础、OAuth 2.0 / OpenID Connect、OWASP API Security Top 10。
- 《Designing Data-Intensive Applications》用于数据库、流、可靠性和分布式系统基础。
- 《Building LLM Powered Applications》和《AI Engineering》（注意选择最新版本）可作为体系化书籍，但示例 API 可能过时，应对照官方文档。

## 5. 如何阅读资源

每学一个主题都产出四样东西：最小示例、失败示例、自动化测试、在博客中的实际应用。用自己的话回答“它解决什么问题、何时不该用、失败时如何发现、成本和安全边界是什么”。做到这些，知识才从教程记忆转为工程能力。
