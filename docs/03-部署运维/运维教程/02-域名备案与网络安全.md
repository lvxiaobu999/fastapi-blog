# 域名、备案与网络安全

## 1. 域名购买

1. 在阿里云域名控制台查询并购买域名。
2. 使用真实主体完成域名实名认证，主体应尽量与备案主体一致。
3. 开启自动续费，设置有效的联系人邮箱和手机。
4. 开启注册局安全锁/禁止转移等保护（产品支持时）。
5. 不要在代码或镜像里硬编码域名，Nginx 和 DNS 分别管理入口。

## 2. ICP 与公安备案

- 服务器在中国大陆且提供网站访问时，域名通常需要 ICP 备案。
- 备案期间按阿里云要求准备主体证件、负责人核验、网站名称与服务内容。
- 取得备案号后，在网站页脚按要求展示并链接工信部备案系统。
- 网站开通后，根据当地要求在规定时间内办理公安联网备案并展示编号。
- 中国香港/海外节点通常不要求 ICP，但不能因此获得与大陆节点相同的访问质量。

规则可能变化，以工信部、公安机关和阿里云备案平台当时要求为准。不要在备案通过前把大陆
节点正式面向公网提供网站服务。

## 3. DNS 解析

为根域和 `www` 配置：

```text
@      A/CNAME -> ECS EIP 或 SLB 地址
www    CNAME   -> 根域/SLB 地址
```

上线前可将 TTL 设置为 600 秒，稳定后适当提高。先验证服务器，再切 DNS；回滚时可快速切回。
不要把 RDS 或 Tair 内网地址配置到公共 DNS。

## 4. HTTPS 证书

1. 在阿里云 SSL 证书服务申请证书，或使用其他可信 CA。
2. 通过 DNS 验证域名所有权。
3. 将证书文件放在 ECS 的受限目录，例如 `/opt/fastapi-blog/secrets/tls/`。
4. 私钥权限只允许 root/部署用户读取，不提交 Git、不 COPY 进镜像。
5. 配置到期告警和自动续签流程；续签后执行 `nginx -t` 再 reload。

## 5. ECS 基线安全

- 使用受支持的 Alibaba Cloud Linux/Ubuntu LTS，及时安装安全更新。
- 禁止 SSH 密码登录，使用密钥；禁止 root 直接远程登录。
- 创建专用部署用户，只授予必要 sudo/Docker 权限。
- 安全组公网只开放 80/443，22 限制来源。
- 安装云安全中心 Agent（按采购版本能力使用），开启登录和漏洞告警。
- 启用时间同步；日志、JWT 过期和 TLS 都依赖准确时间。
- Docker Socket 等同 root 权限，不向应用容器挂载 `/var/run/docker.sock`。
- 不在命令历史、工单、聊天或截图中暴露数据库 URI、Redis URL、Cookie、JWT、证书私钥。

## 6. 数据服务安全

- RDS/Tair 仅使用 VPC 内网地址。
- 应用账号不要使用数据库高权限管理员账号。
- 启用 RDS 自动备份、删除保护，并定期做恢复演练。
- Redis 不允许匿名访问，不对公网开放；生产使用独立账号/密码。
- 如果连接跨越不可信网络，启用数据库/Redis TLS；同 VPC 也应根据合规要求决定是否启用。
