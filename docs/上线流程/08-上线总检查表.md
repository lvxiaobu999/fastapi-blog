# 上线总检查表

本页用于正式上线会议逐项勾选。每个勾选项必须有证据或负责人，不能用“应该没问题”代替。

## 1. 主体、域名和合规

- [ ] 阿里云账号、域名实名和备案主体已确认。
- [ ] 正式域名已续费/开启到期提醒。
- [ ] 中国大陆站点 ICP 备案状态允许上线。
- [ ] 页面已展示正确 ICP 备案号和工信部链接。
- [ ] 公安联网备案计划/编号和页面展示已确认。
- [ ] 隐私政策、用户协议/评论规则与实际数据处理一致。
- [ ] 上传、评论、用户投诉和内容处置责任人明确。

## 2. 云资源和网络

- [ ] ECS、RDS、Tair 同地域、同 VPC。
- [ ] ECS 使用固定公网地址或 EIP。
- [ ] 22 只允许管理员来源。
- [ ] 公网只开放 80/443，未开放 8000/5432/6379。
- [ ] RDS/Tair 白名单只允许 ECS 私网来源。
- [ ] ECS 到 RDS/Tair TCP 连通。
- [ ] RDS/Tair 删除保护、备份和监控已开启。
- [ ] ECS/数据盘快照和 media 远端备份已配置。

## 3. 发布版本

- [ ] Git tag/commit 已评审，生产工作树干净。
- [ ] `uv sync --frozen`、`uv lock --check` 通过。
- [ ] `uv run ruff check .` 通过。
- [ ] `uv run ruff format --check app migrations tests` 通过。
- [ ] Pytest 仅在确认隔离的测试数据库执行并通过。
- [ ] Alembic 只有一个 head，待执行 Migration 已人工审查。
- [ ] Docker Image ID 已记录，不只记录 `latest`。
- [ ] 镜像不含 `.env*`、数据库、上传、日志或私钥。
- [ ] `docker compose ... config -q` 通过。

## 4. ECS 文件和权限

- [ ] `/opt/fastapi-blog/current` 是目标版本。
- [ ] `/opt/fastapi-blog/config/app.env` 权限受限。
- [ ] `app.env` 不在 Git 工作树，未进入镜像。
- [ ] `ENV=production`、`AUTH_COOKIE_SECURE=true`。
- [ ] `ALLOWED_HOSTS` 是准确域名 JSON 数组。
- [ ] 数据库/Redis 使用 VPC 内网地址。
- [ ] `SECRET_KEY` 为独立随机值且至少满足 Settings 长度要求。
- [ ] `/opt/fastapi-blog/data/media` 挂载并允许 UID 10001 写入。
- [ ] TLS 目录有 `fullchain.pem`、`privkey.pem`，私钥权限正确。
- [ ] `nginx -t` 通过。

## 5. 数据库迁移

- [ ] 已二次确认 RDS 实例 ID 和数据库 `fastapi_blog`。
- [ ] 迁移前手工备份任务已经完成。
- [ ] 生产 `alembic current` 符合预期。
- [ ] `alembic upgrade head` 只由一个终端执行。
- [ ] 升级后 `current` 与 `heads` 一致。
- [ ] 没有使用 `stamp`、`downgrade` 或手工删表排错。

## 6. 容器和健康

- [ ] app 状态 healthy，Nginx 状态 running。
- [ ] app/Nginx 没有持续重启。
- [ ] `/health/live` 返回 ok。
- [ ] `/health/ready` 返回 ready。
- [ ] 容器日志没有未处理异常或 Secret。
- [ ] Docker 日志轮转配置生效。
- [ ] FastAPI 8000 没有映射到公网。

## 7. DNS 和 HTTPS

- [ ] DNS A 记录指向预期公网 IP/EIP。
- [ ] HTTP 301 到固定 HTTPS 域名。
- [ ] TLS 证书域名、链和有效期正确。
- [ ] 证书到期告警和续签负责人明确。
- [ ] CSP、nosniff、Referrer-Policy、X-Frame-Options 等安全头存在。
- [ ] `X-Request-ID` 存在并能在日志中定位。
- [ ] HSTS 仅在确认所有相关子域支持 HTTPS 后启用。

## 8. 业务验收

- [ ] 首页、分类、搜索、文章详情正常。
- [ ] 下架文章不会出现在公开接口或页面。
- [ ] 注册、登录、Refresh、改密、退出、注销正常。
- [ ] Refresh Cookie 有 Secure、HttpOnly、SameSite 和正确 Path。
- [ ] 普通用户 403、无身份 401、资源不存在 404 正确。
- [ ] 管理员创建/编辑/上下架文章正常。
- [ ] 头像和文章横图上传正常。
- [ ] 重建 app/Nginx 后已上传文件仍存在。
- [ ] `wss://` 评论、回复、广播和历史加载正常。
- [ ] 错误响应不泄露 Traceback、Secret 或完整内部 URI。
- [ ] 日志不记录密码、JWT、Cookie、Secret 和完整连接串。

## 9. 备份、监控和回滚

- [ ] RDS 自动备份、日志备份/PITR 和失败告警已确认。
- [ ] media 已备份到 ECS 之外的位置。
- [ ] ECS CPU、内存、磁盘、inode、网络和实例告警已开启。
- [ ] RDS 连接、慢 SQL、CPU、存储和备份告警已开启。
- [ ] Tair 连接、内存、延迟、拒绝、淘汰和可用性告警已开启。
- [ ] 域名、证书和云资源到期告警已开启。
- [ ] 上一个 Git tag/镜像仍保留。
- [ ] 已判断本次 Migration 是否允许只回滚应用。
- [ ] 恢复负责人、维护窗口和通知渠道明确。

## 10. 首次部署命令顺序

这些命令只是顺序速查，变量和安全前置见前面分册：

```bash
cd /opt/fastapi-blog/current
export APP_DOMAIN=<APP_DOMAIN>
export APP_IMAGE_TAG=$(git rev-parse --short HEAD)
export APP_ENV_FILE=/opt/fastapi-blog/config/app.env
export MEDIA_HOST_PATH=/opt/fastapi-blog/data/media
export TLS_HOST_PATH=/opt/fastapi-blog/secrets/tls

docker compose -f compose.production.yaml config -q
docker compose -f compose.production.yaml build --pull app
docker compose -f compose.production.yaml run --rm --no-deps nginx nginx -t
docker compose -f compose.production.yaml run --rm app uv run alembic heads
docker compose -f compose.production.yaml run --rm app uv run alembic current

# 只有 RDS 目标、备份和 Migration 审查完成后才执行：
docker compose -f compose.production.yaml run --rm app uv run alembic upgrade head

docker compose -f compose.production.yaml up -d
docker compose -f compose.production.yaml ps
docker compose -f compose.production.yaml logs --tail=100 app nginx
docker compose -f compose.production.yaml run --rm app uv run alembic current
```

## 11. 立即停止上线的情况

出现任意一项就停止：

- 不确定当前连接的是哪个 RDS 数据库。
- RDS 备份仍在执行或恢复能力没有确认。
- Git 工作树有无法解释的修改。
- Alembic 出现多个 head、未知 current 或未审查 Migration。
- 镜像/日志/截图包含 Secret、Cookie、Token 或私钥。
- app readiness 失败或容器持续重启。
- HTTPS 证书域名/链错误，需要依赖 `curl -k` 才能访问。
- media 不是持久挂载或容器无法写入。
- 大陆站点备案/页面展示等正式开放条件未满足。
- 不知道新数据库结构是否允许旧应用回滚。
